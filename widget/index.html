  Cómo instalarlo
  

    

      

        
1

        

      

      

        
Elige indicadores, estilo y tema arriba

        
Tarjetas sirve para destacar los valores, Lista para barras laterales y Fila compacta para encabezados o pies de página. La vista previa usa datos reales.

      

    

    

      

        
2

        

      

      

        
Copia el código con el botón "Copiar código"

        
Son un par de líneas: un contenedor y un script que se encarga del resto (estilos, datos y enlace a indicadoreschile.cl). No necesitas instalar nada. Si tu editor no permite scripts, usa la opción iFrame.

      

    

    

      

        
3

      

      

        
Pégalo en el HTML de tu sitio donde quieras mostrarlo

        
Los valores se actualizan solos cada vez que alguien visita tu página (UF y dólar a diario, UTM e IPC cada mes). No requiere base de datos ni backend. Fuente: Banco Central y SII.

      

    

  


  
  Datos abiertos — úsalos directamente
  
Si prefieres construir tu propia integración, estos archivos JSON son públicos, gratuitos y se pueden consultar desde cualquier sitio. Se actualizan varias veces al día con datos del Banco Central y del SII. Si los usas, agradecemos un enlace a indicadoreschile.cl.


  

    GET
    https://indicadoreschile.cl/data/hoy.json
    Todos los indicadores del día: UF, dólar, euro, UTM e IPC
  

  

    GET
    https://indicadoreschile.cl/data/uf-2026.json
    UF de todo el año 2026 (también dolar-2026.json y utm-2026.json; años desde 2024)
  

  

    GET
    https://indicadoreschile.cl/data/ipc.json
    IPC mensual desde 2020
  

  

    GET
    https://indicadoreschile.cl/data/uf.json
    Últimos días de la UF (también dolar.json y utm.json)
  


  
  Ejemplo en JavaScript puro
  

    

      JavaScript — fetch a los datos
      
    

    
// Todos los indicadores del día
fetch('https://indicadoreschile.cl/data/hoy.json')
  .then(r => r.json())
  .then(data => {
    console.log('UF:', data.uf.valor);
    console.log('Dólar:', data.dolar.valor);
    console.log('UTM:', data.utm.valor);
    console.log('IPC mensual:', data.ipc.valor + '%');
  });

// UF de todo el año (la serie viene de la fecha más reciente a la más antigua)
fetch('https://indicadoreschile.cl/data/uf-2026.json')
  .then(r => r.json())
  .then(data => console.log(data.serie[0]));
